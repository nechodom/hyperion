How a letter's language is chosen
  • A site's own language wins (set on the site's page), then its care package's, then Customer letters here. Headings, month names, number separators and plural endings follow it; the panel itself stays English.
  • Your wording is written in names the language you wrote your letters and sentences in. Set it, and they are used only in letters of that language — a Czech sentence never lands in an English letter, which gets the built-in wording instead. Not specified, your wording goes into every letter, whatever its language.
  • The billing reminder tells you to invoice a client, so it follows the customer letters unless you pin it.

Replace the wording from a file

Paste an edited hyperion-letters.toml (from Download all wording). Sentences the file does not mention keep their wording, so a few lines are a valid paste; an id this version does not know is named back to you. Ids work quoted or not — "care.subject" or care.subject.

What is stored

Only what you change. A sentence left exactly as the built-in wording — including one the fill button put there — is not stored, so later improvements to it still reach you; change one character and it becomes yours. Words in braces are filled in by the server, and a misspelt one stays in the letter as typed rather than vanishing.

Why the logo is embedded

Notifications go out as HTML with a plain-text alternative, so a mail client that refuses HTML loses nothing. The logo travels inside each message rather than as a link: mail clients block remote images by default, and a linked logo would show as a broken box for most recipients. The file is checked by its content, not by its name.

How it is measured
  • Core Web Vitals need a browser to render the page, which a node does not have — hence the source. The render and speed half of the report comes from the node's own site check either way.
  • PageSpeed Insights works without a key at a low rate limit, enough for a weekly check per site; a free key comes from the Google Cloud console (enable the PageSpeed Insights API). The key is {% if chrome.has_nodes %}copied to every node by the settings sync and {% endif %}sent only to Google; the site's address goes to Google when it is measured.
  • Lighthouse gives lab data only, and the headless Chrome it runs uses real CPU and RAM while it measures.
  • Care-plan sites are re-measured with the weekly site check, so the interval can be longer than a week but not shorter. Measure now on a site's Performance panel runs it any time.
