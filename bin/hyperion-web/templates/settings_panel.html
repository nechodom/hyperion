What happens when you save
  1. The hostname is checked in DNS (unless you skip it).
  2. It is saved as cluster.panel_hostname.
  3. The nginx site /etc/nginx/sites-enabled/hyperion-panel.conf is written with a temporary self-signed certificate, so the reload cannot fail.
  4. nginx is tested and reloaded.
  5. A Let's Encrypt certificate is requested in the background; the certificate status in this card follows it.

How safe mode works

The running binaries are copied aside before the update and put back if the node is not healthy afterwards. That restores binaries, not data — database migrations only ever add, so an older binary still starts against the newer schema.

An unattended apt upgrade has a much bigger blast radius than a Hyperion update, so system packages are left to you: run them from Nodes while you are watching.
