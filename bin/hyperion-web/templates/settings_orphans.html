What counts as left over
  • A site deleted without ticking “Also delete this site's backups from the off-site FTP target” leaves its files on the target, and nothing in the panel points at them any more.
  • A file counts when no hosting on any node uses its domain as its name or an alias, sites in the trash included. If any node does not answer, nothing counts: that node could be hosting the site.
  • The domain is read from the file name, which a backup run writes as <domain>-<time>.tar.gz, .tgz or .sql. Anything else is listed as unknown and cannot be deleted from here.
  • Nothing goes unless you tick it. These can be the only copy of a site that is gone, and a delete cannot be undone. An archive and its database dump are two files: tick both.
  • Every node is asked again when you delete, and a file whose domain has come back since is left alone.
