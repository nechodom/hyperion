One clamscan per node reads every file of every scanned site, except media and files over 64 MiB. It runs only on nodes where ClamAV is installed, and takes minutes to hours depending on how many files there are.

Off: nothing starts by itself. Run now on the Antivirus page still works.

ClamAV loads over a gigabyte of signatures and is capped at 3 GiB. A node with less than this available skips the pass and tries again every ten minutes while the window is open.
How the schedule is read

A pass is due once the chosen number of days has gone by since the last one began, and starts in the first hour of the window after that. A window whose end is before its start runs past midnight (22:00 to 04:00). A pass that is running when the window closes is not cut off; it is stopped only after six hours.

A pass that could not start or was interrupted by a restart is tried again the next day rather than a whole interval later. One the kernel stopped for lack of memory rests for a week, unless someone runs it by hand.

Each node reads this when it checks whether a pass is due, so a change applies without a restart, as soon as the settings sync has delivered it.
