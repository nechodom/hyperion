What is counted

Failed logins are read from four sources: each site's own access.log (POSTs to wp-login.php and xmlrpc.php) and the node-wide ssh, ftp and mail journals. WAF refusals are counted per site on top of those.

Website login is counted per site, so the ban is recorded against that site and appears in its care report. It is the only source that can be switched off for one site: the Brute-force bans tile on the site's Security card. The ssh, ftp and mail journals cover the whole machine and belong to no single customer, so they stay on for everyone.

WAF refusals are requests a site's WAF turned away for a rule no honest visitor or crawler trips over and over: attack patterns in the URL, vulnerability scanners, sensitive WordPress files, repository and secret files. Download, XML-RPC, country and bot refusals never count.

Who is never banned, and other limits

Only public, routable addresses are banned automatically. Private, loopback, CGNAT and link-local addresses are skipped, because a node-wide drop on those is an outage: webmail talking to dovecot, the master↔node link, a NAT gateway in front of a whole office. You can still block any address by hand from a site's Settings & limits tab.

An address already banned within the look-back gets the repeat-offender length instead of the first-offence one; a look-back of 0 never escalates. A ban shorter than a minute is refused, because the ban list reads a zero length as never expires.

Panel logins are guarded separately: repeated failures are throttled, then the address is firewalled for an hour. These numbers do not govern that.

How it works

The database is MaxMind's free GeoLite2 Country. The credentials are read from /etc/GeoIP.conf, the same file MaxMind's own geoipupdate uses, so if you already run that tool there is nothing to enter here. A key saved here is written to that file, readable by root only, and never shown on this page again.

Saving downloads the database straight away, so a wrong key fails now rather than unnoticed later. Hyperion does not refresh it on a schedule: refresh it now and then. MaxMind publishes twice a week, so refreshing more often downloads the same data again.

Until it is installed every visitor resolves to ZZ and no country rule matches, so no site is cut off by a rule set before the data existed.
