Import hosting from another node

On the source node, open the hosting, choose Move or copy → Export a transfer file. Its result page shows a base URL and a token; paste both here. This node downloads the transfer file directly and provisions an identical hosting.

What happens next

  1. This node downloads manifest.json and archive.tar.gz from the source over the signed URL.
  2. The archive's BLAKE3 digest is checked against the manifest, so a corrupted transfer is refused.
  3. A fresh hosting is provisioned with the source's domain, aliases, PHP version and database engine, and the archive (htdocs plus the database dump) is restored into it.
  4. You land on the new hosting. Point DNS at this node, then click Issue certificate once it resolves. Private keys never travel between nodes.
  5. Once the imported site works, delete the hosting on the source.
