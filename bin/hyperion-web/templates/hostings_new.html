What happens next

When you create the site, Hyperion sets everything up for you — the files, the runtime and database if your type needs them, and the web server — then takes you to the site's page.

It is all-or-nothing: if any step fails, Hyperion undoes the earlier ones, so you never end up with a half-created site.
