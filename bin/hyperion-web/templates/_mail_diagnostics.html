What these do

Re-check runs every check again; a DNS change can take a few minutes to show.

Reconfigure postfix re-applies what the agent applies when it starts — smart host when the node's relay is on, direct delivery when it is off — without restarting anything. Use it after editing agent.toml by hand.

Test via local sendmail hands one message to /usr/sbin/sendmail, exactly as a site's mail() does. Success means postfix queued it; the delivery shows in the mail log a few seconds later. The test on Settings → Mail talks to the relay directly and skips postfix.
